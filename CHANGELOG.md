# Changelog

## 0.1.0 — 2026-10-11

First public release.

- Topic-scoped Learn and Learned modes with user-controlled transitions.
- An evolving Brief that separates user statements, inferences, and corrections.
- English instructions with responses in the user's language.
- Conversation-only operation when file writing is unavailable.
- Bilingual introduction, installation guidance, examples, and public specification.
- Local installer with overwrite protection; reproducible runtime archive and checksums.
- Behavioral evaluation scenarios and explicit validation limits.

The behavioral core is unchanged from the development version exercised in 13 synthetic interaction turns.
