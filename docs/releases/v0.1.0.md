# Learning Machine v0.1.0

The first public version of Learning Machine: a small Agent Skill for exploring a topic through questions, then answering with the context built together.

## Start

```bash
npx skills add yifanRex/learning-machine --skill learning-machine
```

Then: “Use learning-machine to explore my side project. Ask me questions before giving advice.”

Say **answer now** to answer, and **ask me** to explore again. Chinese equivalents **开始回答** and **继续问我** work too.

## Included

- Learn and Learned modes with user-controlled switching.
- An editable, session-scoped Brief with distinct facts, inferences, and corrections.
- No runtime dependencies, account, database, or external service.
- English and Chinese introductions, install instructions, examples, and a public spec.
- Reproducible runtime archive with a SHA-256 checksum.

## Validation

The core was exercised in four independent synthetic conversations totaling 13 turns in the development host. Packaging and installer checks are separate. This is an initial release, with no claim of cross-host reliability or better outcomes than direct conversation.

Feedback is most useful when it shows a question that was unnecessary, a missed correction, or a specific way the Brief improved—or failed to improve—an answer.
